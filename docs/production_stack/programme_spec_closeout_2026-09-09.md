## Initial numerical targets and subsequent calibration

Retain the pilot's recommended numerical requirements as initial working targets, supported in the 10 September owner review. They may evolve as real data reveals an unsuitable definition, applicability rule or threshold. Record a versioned, evidence-backed amendment and its measured effect under section 11 of the measurement register. Material changes to acceptable risk return to the owner; routine measurement corrections can proceed within authorized work. The preparation added a measured local citation budget, without changing targets to make the current data pass.

| Area | Recommended requirement |
|---|---|
| History | 100% obligation accounting, with evidenced eligible-empty/unavailable states rather than silent omissions |
| Roster accuracy | Per quarter: >=99% FV recall/precision and >=95% row recall/precision; per-fund floors >=95% FV and >=90% rows |
| Amount fields | >=99.5% correct at source precision; no extra blanket relative tolerance |
| Other numeric fields/dates | >=99% correct, retaining applicability, missingness, partial precision and unsupported-value errors separately |
| Reconciliation | Non-netted absolute primary-anchor error <=0.25% per quarter; ordinary per-fund limit <=1%, with source rounding and zero-total handling |
| Reference assessability | All eligible fund-quarters dispositioned; comparable primary anchors >=95% of eligible funds and >=99% of source-side FV before a cohort monetary accuracy claim; unknown denominator prevents a pass |
| Entity and position links | >=99.5% precision and >=95% recall separately; >=95% complete source-supported chains |
| GICS sector | >=95% accuracy, >=95% absolute-FV availability and >=90% row availability; inference/default/unknown methods visible |
| Evidence | 100% path-or-explicit-unavailable representation; zero misleading links; >=99% reported-amount FV and >=95% reported numerical observations correctly highlighted; complete calculation/inference paths |
| Local citation navigation | p95 <=5 seconds on the declared local desktop workload; remeasure deployment/device/network conditions before public performance acceptance |

For sampled accuracy, use a one-sided 95% bound with the actual sampling/cluster design. A perfect small sample does not establish 99.5% accuracy. Exact source censuses can be assessed directly. Development exposure remains recorded; the current 61-cluster pilot cannot certify the whole population.

The executable proposal currently returns `FAIL_WITH_UNASSESSED_ITEMS`. That is the expected and correct outcome. D12 approval would approve the **requirements**, not certify that the present pipeline meets them. The existing live quarter-acceptance JSON and historical sign-offs are unchanged.
