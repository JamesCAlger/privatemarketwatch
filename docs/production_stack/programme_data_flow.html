      One observation is one position or lot at one date. Company resolution links borrowers; it does not combine their different instruments.

      Gold is a data layer, not an approval. A candidate can fail its checks and remain available for investigation.

      All input versions, registry state and output hashes belong to one candidate. Completed work is reusable when those dependencies still match.

      The agent remediation loop

      Alongside the data layers

      Agents investigate failures or enrichment gaps. Their admitted rules and decisions become inputs to a new candidate; the current candidate stays frozen.

      → → →
      ↶ New candidate, new frozen input manifest. Back to control inputs

      Reported, calculated and inferred stay distinct.

      A disclosed fair value, an FV-based cost proxy and an inferred GICS sector have different evidence trails. Source review does not turn an inference into a reported value.

      Source totals have their own path.

      Independent fund NAV supplies calculated percentages. Independent investment totals support reconciliation. They are not rebuilt from the holdings being checked.

      One public population, several views.

      Headline FV and industry/instrument breakdowns use the same cohort holdings. Subsidiary-aware reconciliation uses its separately defined accounting population.
