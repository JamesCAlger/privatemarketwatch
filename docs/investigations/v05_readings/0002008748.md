`_get_prefix_rules_data()` (every v3 wrapper with a non-empty `dispatch.prefix_rules`), joined into

    NOT regexp_matches(_raw_id, '(?i)^(?:<prefix_rules keys>)(?:\s|-|$)')

i.e. "a bare entity name with no instrument word is an issuer subtotal". A row escapes only when the
wrapper disposition is `*_position_leaf` (line 1605); the wrapper leaves bare issuer members with no
disposition on purpose (edge case LORD_ABBETT_BARE_ISSUER_MEMBERS_EARLY_TAXONOMY), so nothing rescues them.

### Why thirteen pass
The identifiers are humanised member names with no punctuation. 'JFL Atomic Acquisition Co Inc',
'Continental Buyer Inc', 'Playpower Inc', 'Kravet Inc', 'GCOM', 'Electro Methods' contain none of the
entity strings: 'inc.'/'inc,'/' inc ' need a following character, ' co.' needs a period. Names with
'llc', 'group', 'limited', ' plc' match and are dropped ('Holdco' names drop because they also end in LLC).

### Smallest generic fix
A wrapper switch that leaves 2d out for a filer whose bare entity rows are positions, e.g.
`staging.bare_entity_rows: "positions"` (or a `dispatch` key), read where `_pr_hier_conds` is assembled
(line 877): skip the fourth condition for that CIK. 2a-2c stay. Set it for 0002008748. Tests: a bare
'Spark Buyer LLC' row with rate and maturity survives for a switched filer; the same row for an unswitched
prefix_rules filer is still dropped. I do not recommend deleting the wrapper's prefix_rules instead: the
wrapper classifier also reads them and I did not test that.
Consequences to check when applying:
- The restored rows come out as LOAN / DIRECT_LENDING with issuer = identifier, like the 13 already published. That is
  wrong for 'SBLA Private Credit LLC' (a JV interest, no rate, no maturity) and 'Arkas Bidco Limited' / 'Two'
  (equity, industry member 'PersonalCareProductsEquity'). They need a class from the industry member
  (InvestmentsInJointVenture -> fund/JV interest; '...Equity' -> equity) or wrapper equity/JV labels.
- Source reconciliation labels Flourish (22.9M) a self-referential subtotal and Arkas (0.888M) a hierarchy header;
  those labels need to agree with staging afterwards.
