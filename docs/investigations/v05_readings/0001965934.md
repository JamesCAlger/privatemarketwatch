### Fixes
1. T-bill rows 2025-06-30 to 2025-12-31 (478.9M over three quarters).
   - Works today, no code: `source_encodings.context_identifiers`, three entries
     "0000950170-25-109383 C_c76d3700-980c-4440-be68-efa8999a8a7c => U.S. Treasury Bill",
     "0001193125-25-272318 C_01f0afac-076d-4ec3-9d0d-5d4a2d99ff01 => U.S. Treasury Bill",
     "0001193125-26-117368 C_985fc7a8-0626-4580-a745-4c28b52f7160 => U.S. Treasury Bill".
     Same identifier as the filer's own 2024-12-31 and 2025-03-31 rows. Per filing, so it does not carry forward.
   - Carries forward: `source_encodings.page_labelled_contexts: ["investmentissueraffiliationaxis+investmenttypeaxis"]`.
     It does NOT work as the code stands: row_cells.py shows the printed row's cells are
     ['U.S. Treasury Bill', '-', '4.32 %', '10/21/2025', '218,000', ...] and `row_identifier`
     (`pipeline/page_labelled_contexts.py` line 64) needs letters in the second cell, so nothing is adopted. It needs a
     shared change: accept a dash placeholder in the second cell and use the label alone. 'Total Debt Investments' on
     the same axis pair is still refused (label starts with 'Total'). Needs a false-positive test on 0001901612 and 0001930087,
     who already use this setting.
2. Class of the T-bill. The wrapper's non_private_markers make it CASH, so even when present (2024-12-31, 2025-03-31)
   the published investments stay under the filed total by the T-bill. The filer counts it inside 'Total Investments'
   and the money funds outside. Owner decision: keep CASH and accept the totals difference by a recorded reason, or
   class T-bills as an investment row for this filer. `investments_total_excludes: ["cash_rows"]` does not fit (the
   filed total includes the T-bill and excludes only the money funds).
3. Money market funds from 2025-06-30 (22.895, 29.677, 9.794, 56.749M; published as CASH in the four earlier quarters,
   absent since). `source_encodings.fair_value_concepts: ["CashEquivalentsAtFairValue"]` reads the filer's own concept
   (existing key, as Golub). Not tested. Cost is not tagged on those contexts.
4. Summit Materials 2024-06-30 (4.015M): filing error on one row.
   `context_identifiers: ["0000950170-24-097213 C_763ab5d1-0a1f-41c7-9e09-7ceab23d09dd => <identifier in the filer's form>"]`
   only if a context that already carries an identifier can be renamed; `name_declared_contexts` skips contexts that
   are already investments, so this one probably needs a one-row correction instead. Not tested.
