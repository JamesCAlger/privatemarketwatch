## A. The totals gap (the open question) - fully explained, every quarter

The filing has TWO tables. (1) The schedule proper, ending
"Total Investments - non-controlled/non-affiliated 4,487,395 4,443,900 205.95" then
"Short-Term Investments BlackRock Liquidity T-Fund - Institutional Shares (14) ... $ 49,874 $ 49,874 2.31 %",
"Total Investments at fair value $ 4,537,269 $ 4,493,774 208.26 %" (0001193125-26-221769).
(2) A separate memo table "Investments--non-controlled/non-affiliated | Commitment Type | Commitment Expiration
Date | Unfunded Commitment (1) | Fair Value (1)", e.g. "AAH Topco., LLC Delayed Draw Term Loan 4/1/2027 $ 3,179 $ ( 8 )",
ending "Total Unfunded Commitments $ 1,087,013 $ ( 9,492 )".

Table (2) is NOT part of Total Investments. Its rows are tagged (identifier "... Commitment Type ... Commitment
Expiration Date ...", facts InvestmentCompanyFinancialCommitmentToInvesteeFutureAmount + InvestmentOwnedAtFairValue)
