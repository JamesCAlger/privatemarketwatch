## 5. Proposed fixes

- F1. Wrapper `schedule_row_tags` (as built for Barings): an identifier-axis context is a position only
  if it carries a principal, shares or percent-of-net-assets tag. Measured on this fund: removes exactly
  c-708, c-729, c-911, c-913; 2024-12-31 then ties on fair value and cost. Retire
  `exclude_nonaccrual_aggregate_duplicates` (it names three identifiers and two quarters).
- F2. Replace `exclude_newcred_lookthrough_rows` (quarters pinned to 2025-09-30, 2025-12-31, 2026-03-31)
  by a wrapper setting that marks rows on `InvestmentCompanyNonconsolidatedSubsidiaryAxis` as
  `underlying_schedule` (retained, not published), with no quarter list.
- F3. Reference rate from the printed "Reference" cell: `reference_rate_columns: ["Reference"]`, codes
  SOFR, P (Prime), SONIA, EURIBOR / Euribor, BBSY, Fixed; strip the reset letter "(D|M|Q|S|A)" and the
  asterisk. A row printing "SOFR(x)* + n %/PIK" is floating with spread n (all PIK): set coupon type and
  reference from the cell, and publish the PIK part as the whole coupon (owner question D-092).
- F4. `source_encodings.principal_usd_reference: ["fred_h10"]`.
- F5. Equity rows: a principal tag in usd on an equity-family row of this filer is the share count.
- F6. `dispatch` instrument regex of 3c for the comma format (2024-12-31 to 2025-09-30).
- One row, filing wrong: c-64 (2024-12-31) is Wealth Enhancement Group subordinated, not KWOR.
- Two rows, filing wrong unit: c-327 (EUR tagged gbp), c-269 (USD tagged gbp), 2026-03-31.
