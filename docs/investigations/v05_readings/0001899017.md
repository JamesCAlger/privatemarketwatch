## 6. Proposed fixes

- F1. Unscaled money facts. Generic guard, switched by wrapper: in a filing whose identifier-axis money
  facts are at decimals -3, a fair value / cost / principal fact at decimals 0 that is not a multiple
  of 1,000 is in thousands; multiply by 1,000. Rows: KAMC x2 (2025-09-30, fair value only), Spotless
  Brands and Spindrift (2025-12-31, all three facts), Engineered Products principal (2025-12-31,
  2026-03-31), 11 SLP II rows (2025-06-30). No direct row before 2025-09-30 has such a fact (query
  unscaled.sql).
- F2. Wrong-dated current rows: in a filing, an identifier context dated at a quarter end that is
  neither the period end nor the prior fiscal year end, whose identifier has no context at the period
  end, is the current row. Six rows 39,978 (2025-12-31), one SLP II row (2025-09-30). Same rule finds
  the AB Private Credit row (0001634452, 2025-06-30).
- F3. `source_encodings.foreign_unit_values: ["reported_in_usd"]` for fair value and cost. Principal on
  these rows is in the foreign currency as tagged, so the setting must not relabel principal.
- F4. Pull `column_remap.json`; retire the SLP II exclusion rule; subsidiary axis -> `underlying_schedule`.
- F5. Issuer / industry / instrument regex of 3c as the wrapper's split.
- F6. Rows with a cost tag and a dash for value: publish with fair value 0. No cost proxy where the page
  prints a dash for cost.
- F7. Reference codes BBSY, BKBM, P in the member reader; or read the tagged enumeration from 2025-03-31.

Expected after F1 to F4: 2025-09-30, 2025-12-31 and 2026-03-31 tie on fair value to within 1; cost at
2025-12-31 within about 0.5M (dash rows).
